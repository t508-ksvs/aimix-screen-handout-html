SUBJUNCTIVE TIME-STEP-BACK FORMULA
說反話 ＝ 拉開心理距離 ＝ 動詞往過去「退一格」！
STEP 1 手繪時間軸「動詞退格術」符號系統（Visual Time-Shift） 動詞的過去式不只代表過去時間，更代表「非真實、假想的心理距離」
① 真實時空
REALITY / FACT
【事實客觀基準】 真實世界的時間基準線，陳述客觀事實或客觀條件，動詞保持原本時態（現在式/過去式）。
② 與現在相反
PRESENT COUNTER
【退一格到「過去」】 當下說反話（現在沒錢、現在不是鳥），動詞時態立刻往左退至過去式（be動詞一律 were）！
③ 與過去相反
PAST COUNTER
【退一格到「過去完成」】 歷史不能重來（事後諸葛與悔恨），從過去事實再往左退至 had p.p.！
④ 未來渺茫萬一
FUTURE UNLIKELY
【萬一可能 should】 未來極度渺茫的假設（萬一太陽從西邊升起、萬一他被證實無罪），用 should + 原V。
STEP 2 三大時空假設法全景矩陣（Master Subjunctive Matrix） 時間軸坐標 × 動詞退格公式 × 講義歷屆經典例句
① 真實條件句
REAL CONDITION
If S + V(現在式), S + will/can + 原V
心理視角：可能成真！氣象條件或承諾，副詞子句用現在式代未來式。
If it rains tomorrow, we will stay at home.
（明天真的可能會下雨，客觀因果）
② 與現在相反 (核心)
PRESENT COUNTER
If S + V-ed / were, S + would/could + 原V
心理視角：當下白日夢、說反話！現在事實是假的，退格到過去式/were。
If I had the money, I would buy the dress.
（事實：我現在根本沒錢，買不起！）
③ 與過去事實相反
PAST COUNTERFACTUAL
If S + had p.p., S + would/could + have p.p.
心理視角：事後諸葛、無法挽回的遺憾！從過去退至過去完成式 had p.p.。
If Joe had worked harder, he would have passed.
（事實：他過去沒努力，考試已經被當了）
STEP 3 講義核心概念認知深度圖解（Cognitive Deep-Dives） 李櫻教授 3C 語法：虛擬語氣是表達主觀心態與心理距離的溝通策略
講義金曲引用 · 認知語意反差
① 碧昂絲的假設：真實條件 vs. 當下說反話
【真實條件句】客觀可能
If it is sunny tomorrow, we'll eat...
情境解密：明天可能出太陽，也可能下雨。說話者採取中立客觀立場，不用退格。
【現在相反】白日夢說反話
If I were a boy, I would be a...
情境解密：碧昂絲是女生，當下絕不可能是男生！為了拉開「非事實」心理距離，動詞立刻退格成 were！
歷史不可逆 · 過去相反
② 山崩與車禍的悔恨：事後諸葛 have p.p.
【殘酷的過去事實】
The landslide occurred early.
客觀歷史：山崩提早了數秒發生，公車不幸被落石擊中。歷史已經塵埃落定。
【過去相反假設】退至 had pp
If it had occurred later, the bus could have passed!
語意解密：如果山崩晚幾秒，公車就能安全通過了！退至 had p.p. + could have p.p. 表達扼腕與痛悔。
大考進階必考 · 倒裝特技
③ If 省略大搬風：助動詞衝到主詞前方
【正常語序 If 帶頭】
If I were you...
If he had known...
常規句式：保留 If，讀者一眼辨認出這是條件假設句。
【If 省略倒裝】神級代換
Were I you...
Had he known...
文法特技：把 If 刪掉，動詞（Were / Had / Should）直接飛奔到主詞前面，語氣更加莊重文雅！
動動腦進階題 · 跨時空混搭
④ 跨時空混搭：過去的因，結出現在的果！
【前半句】與過去事實相反
If John had studied medicine before...
時間坐標在過去：當年大學沒念醫學院（過去事實相反，用 had + p.p.）。
【後半句】與現在事實相反
...he would be a doctor now!
時間坐標在現在：他「現在」就會是醫生（現在事實相反，用 would + 原V，不能死套公式配 have p.p.！）。
STEP 4 李櫻教授 3C 語法破除死背迷思 & 歷屆試題秒殺法則 掌握「退格律」的萬能衍生：Wish、As if、It's time 全通用
⚠️ 大考震撼彈：Wish、As if、It's time 全部遵守「退格律」！
【講義歷屆試題精華】
• I wish: "Right now I wish you were here."（現在你不在這，退一格用 were！）
• As if: "The boy looked pale as if he had seen a ghost last night."（昨晚見鬼，過去相反退一格用 had seen！）
• It's time: "Kids, it's time you went to bed!"（該睡了但現在還沒睡，退一格用 went！）
3C語法解析：只要表達「與客觀事實不符的願望或狀態」，英文就會啟動「時態退格」以標示心理落差！
假設法大考解題 3 步定心法
  • 1 定事實：找出句子對照的真實時間是「現在(Now)」還是「過去(Past)」？
  • 2 退一格：現在相反 → 過去式 / were；過去相反 → had p.p.。
  • 3 配主句：現在相反用 would/could + 原V；過去相反用 would/could + have p.p.！
